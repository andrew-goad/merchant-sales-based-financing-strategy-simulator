# Curated Power BI visual evidence

This folder contains a bounded set of presentation-ready captures selected from the owner evidence package. It includes Baseline and Recession Energy views for P01, P02, and P04, plus representative P03 application journeys.

Raw QA screenshots, accessibility dialogs, interaction setup captures, tab-order evidence, and private Desktop working evidence are intentionally excluded from the public-candidate asset folder. Their existence and validation role are documented in the owner-evidence manifest and validation report.
