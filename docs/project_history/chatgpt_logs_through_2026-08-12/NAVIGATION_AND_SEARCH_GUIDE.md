# Navigation and Search Guide

## Fast review

1. Open `CONVERSATION_INDEX.csv` for scope, dates, and transcript paths.
2. Use `PROJECT_CHRONOLOGY.md` for the project’s broad progression.
3. Use `DECISION_AND_MILESTONE_INDEX.md` to locate important design, build, audit, and release topics.
4. Open a transcript and use browser search for a stage, program number, gate, hash, or work-package identifier.

## Duplicate history

The branch and main Merchant POS Lending Simulator exports overlap. They are kept as separate historical conversations because their later branches differ. Review the conversation index and timestamps rather than assuming every repeated message represents a new decision.

## Machine-readable use

JSONL files contain only the published visible record. Each row includes the source message index and the published message index so analysts can distinguish source position from post-sanitization position.
