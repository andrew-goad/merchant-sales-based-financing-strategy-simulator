# Explicit stage boundary

M2.7 creates **synthetic setup blueprints only**.

It does not:

- create a real core-system account;
- change a real payment or remittance obligation;
- use a bank-account or routing number;
- transmit an ACH or payment-network instruction;
- contact a merchant;
- post a write-off or charge-off;
- place an account with a collection agency;
- initiate legal action;
- transmit an external notice;
- generate a production adverse-action notice;
- rewrite accepted M2.6 strategy history.
