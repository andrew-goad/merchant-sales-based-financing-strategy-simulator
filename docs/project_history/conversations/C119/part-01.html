The precise answer

Your confusion is justified. The current P05 design makes Strategy profile look like another underwriting control alongside Scenario, as though changing the profile might re-decide a merchant. That is not quite what R26 implements.

We have merchant-application-level strategy simulation, but not profile-driven re-underwriting.

Question Current R26 implementation
Can a scenario change the merchant’s decision? Yes. Baseline versus Recession Energy can change risk, evidence, capacity, final outcome, funding, and downstream performance.
Can a strategy profile change approve/review/decline? Not in the accepted R26 population. It preserves the source-owned authority class.
Can a profile choose different terms for a merchant application? Yes. It can select a different governed candidate, amount, pricing structure, expected loss, contribution, return, or payment burden.
Is there account-level strategy simulation? Yes, but narrowly. EARLY_INTERVENTION can change post-funding servicing treatment, not re-underwrite the account.
Can you presently select one merchant in P05 and compare all profiles? No. The data supports that analysis, but the current report page does not expose a merchant/application selector or dedicated drillthrough.
Does changing the slicer run a new decision? No. It filters precomputed, source-owned simulation results already loaded into Power BI.

Where profiles fit in the logic

The core decision process remains:

Merchant evidence
→ feature availability
→ risk, capacity and request
→ policy gates
→ candidate search
→ selected structure
→ final decision authority
→ economics
→ funding and activation
→ monitoring and intervention
→ account certification
→ portfolio outcome

The strategy-profile simulation sits after the governed source process.
