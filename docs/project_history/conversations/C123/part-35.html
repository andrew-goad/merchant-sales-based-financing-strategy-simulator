4. How this demonstrates Tableau skill

The goal should be a few well-used capabilities, not a dashboard overloaded with features to prove you know them.

Tableau capability How it earns its place
Calculated fields Derive matched-outcome differences, authorization indicators, and properly labeled rates.
Parameter-driven analysis Switch the segment view between industry and acquisition source.
Dashboard filter actions Click a matrix cell or segment and inspect the corresponding applications.
Level-of-detail calculations, where needed Maintain an intentional comparison denominator rather than letting every click silently redefine it.
Purposeful tooltips and detail presentation Reveal source reasons and comparison context without crowding the executive view.

Tableau supports parameters for switching analytical inputs, filter actions for linking views, and FIXED level-of-detail expressions for calculations at specified dimensions. The important implementation detail is that FIXED expressions respond differently to ordinary filters and context filters; we should choose and test that behavior deliberately.
