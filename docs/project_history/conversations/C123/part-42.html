Yes—and there's a better way to capture the full dashboard than zooming out in Presentation Mode. Since you're preparing screenshots for GitHub and your Bank of America follow-up, I'd use Tableau's built-in image export. It should give you a cleaner, more professional result without the Tableau menus or desktop interface.

Option 1 — Export the entire dashboard as an image (recommended)

  1. Open Risk Decision & Scenario Review in Tableau Public Desktop.
  2. Set your preferred filters, matrix selection, and Segment Analysis Mode.
  3. From the top menu, choose Dashboard → Export Image.
  4. Save the image as a PNG.
  5. Open the exported image and check that Sections 01–05 are visible, including the Baseline and Recession Energy explanations.

Unlike a normal screenshot, this exports the dashboard canvas rather than just the visible portion of your monitor.

One limitation: Tableau won't automatically expand scrollable application tables or narrative panels. The export captures those elements within their existing dashboard dimensions. Make sure both scenario explanations are visible before exporting.

Option 2 — Increase the dashboard's export dimensions

If the exported image is too small or difficult to read, you can give the dashboard a larger canvas.

  1. Open the dashboard in editing mode.
  2. In the left Dashboard pane, find Size.
  3. Select Fixed Size.
  4. Try these dimensions:
    • Width: 1600 px
    • Height: 1400 px
  5. Check that the additional space is distributed appropriately.
  6. Export the image again.

I'd try your current dimensions first. Changing the canvas can affect tiled-container proportions or introduce unnecessary whitespace, and we don't want to disturb the layout you've already established.

Option 3 — Zoom out for a conventional screenshot

If you want to capture the Tableau application itself, rather than export the dashboard, you have a few alternatives:

  • Temporarily change Windows Settings → Display → Scale to 100%.
  • Maximize Tableau and use Presentation Mode.
  • Once the dashboard is published, open it in a browser and press Ctrl + minus (-) until the full page fits.

The browser approach is generally easier than changing Windows display settings, although zooming out may make the text too small to read.
