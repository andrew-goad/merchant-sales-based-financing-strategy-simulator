# The biggest issue: R4 takes too long to “get into it”

You asked specifically about the up-front pages. My answer is:

**Five front-matter pages is not fatal, but R4 delays the highest-energy proof too long.**

R4 structure:

```text
Page 1  Cover
Page 2  Contents & skill guide
Page 3  The case
Page 4  The chronology
Page 5  Reading the record
Page 6  First evidence page begins
Page 8  First human challenge screenshot
Page 13 Routing-rules challenge appears
Page 14 Counteroffer transfer begins
```

So technically the evidence begins on page 6, but the first high-value human-in-the-loop moment is page 8, and the big rules/counteroffer story does not begin until page 13–14. The contents page even advertises that this is a “Complete evidence edition | 70 pages,” which is honest but intimidating for a public reader. [export reference: filecite | turn92file0 | L24-L40]

For an evidence archive, that is fine.

For a flagship marketing piece, it is too slow.

## My recommended fix

Keep front matter to **three pages** in the public version:

```text
1. Cover / thesis
2. What this proves + how to read it
3. Chronology / two correction cycles
```

Then begin the evidence immediately with the first human intervention.

The current page 5 “Reading the Record” is good, but it can become a sidebar or appendix. It does not need to be a full up-front page in the executive version.
