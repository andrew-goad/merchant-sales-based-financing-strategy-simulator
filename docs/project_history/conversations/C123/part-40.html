In Tableau Desktop Public Edition, direct dashboard image export options are disabled in the desktop application menu compared to Tableau Desktop Professional. To save a dashboard image, you must publish the workbook to your Tableau Public profile and download it from the web view. [1, 2]

Step-by-Step Instructions

  1. Save to Tableau Public: With your dashboard open in Tableau Desktop Public Edition, go to Server > Tableau Public > Save to Tableau Public (or File > Save to Tableau Public As...) and sign in with your account. [1, 2]
  2. Open in Web Browser: Once published, the visualization will automatically open on the Tableau Public Website in your default web browser. [1, 2]
  3. Locate the Download Icon: Go to your profile or the visualization page and look at the bottom toolbar or control bar of the interactive dashboard. [1]
  4. Download as Image: Click the Download icon (an arrow pointing down into a tray) and select Image from the menu options. [1, 2]
  5. Save Locally: Choose your preferred image format (such as PNG or JPEG) and save the file to your computer. [1, 2]
