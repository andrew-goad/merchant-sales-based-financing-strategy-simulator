# Production rules for all ten pages

To avoid the repeated micro-correction cycles encountered with the lineage and architecture images:

1. **Regenerate each page from scratch at high resolution.** Do not repeatedly edit flattened output.
2. **Lock the complete copy before image generation.** Titles, stage names, counts, statuses, and footer language should be treated as a factual authority.
3. **Use the existing v2 pages only as style references**, not as the physical editing substrate.
4. **Audit every page at full resolution** for spelling, stage sequence, status language, counts, visual consistency, and overclaiming.
5. **Seal each approved page before beginning the next one.**
6. Maintain:
   - white editorial canvas;
   - deep navy hierarchy;
   - muted teal accepted-state language;
   - restrained signal gold;
   - thin rules and generous spacing;
   - one primary visual idea per page;
   - 15-second executive comprehension.
7. Avoid:
   - tiny stage-level text;
   - raw SQL or database screenshots;
   - generic stock imagery;
   - production claims;
   - causal claims;
   - finished-Power-BI claims where only governed views exist.
