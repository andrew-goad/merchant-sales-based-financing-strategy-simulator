## A readable retained record

The native-export layer contains **24 project conversations and selected passages from 12 mixed-purpose conversations**: **8,034 visible message occurrences**, **5,272 distinct native message identities**, including **59 alternate-path occurrences**. Shared ancestors retain links in every branch; identical words under different message identities remain separate events. Internal reasoning is excluded. Project conversations contain explicitly labeled privacy omissions; mixed-purpose excerpts do not reproduce unrelated discussions.

The project workstreams reach October 16, 2026, including Tableau development and publication; related mixed-purpose excerpts reach October 17. Each conversation has its own observed cutoff in the directory. This is not a claim to cover later exchanges, unavailable attachment contents, or all account activity through the archive assembly date.

## Three connected strands

- **Build and govern:** original design, PostgreSQL execution, Module 2 and Module 3, Campaign Scale and separate review.
- **Question and correct:** Power BI exposes missing explanations; the owner redirects counteroffer strategy, then reopens monitoring after acceptance.
- **Explain and teach:** report production, public narrative refinement, and Tableau presentation make the method and results inspectable.
