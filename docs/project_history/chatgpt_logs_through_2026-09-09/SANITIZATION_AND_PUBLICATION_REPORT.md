# Sanitization and publication boundary

Raw PDFs, raw structured/update archives, private authorities/evidence and complete extraction/redaction intermediates are excluded from the public tree. The private freeze evidence retains exact source identities and preimages. This public derivative keeps professional attribution and relevant project IDs while removing nonpublic contact values, workstation/session paths, secrets, broken session links and complete classified private payloads.

There are **6101 recorded normalization/redaction operations across 480 records**. These are not 6101 material privacy findings. Link normalization, citation/UI cleanup and path/contact omission make up most entries. PUBLIC_OMISSION_REGISTER contains only classifications and digests; full before/after text is private.

Two complete private R22 JSON objects were discovered in an inherited source not yet in R3. Only their full object spans are omitted in the new public history. Permitted source names, hashes and historical PASS descriptions remain. No private original is reclassified as public by its appearance in a conversation.

Existing accepted PDF, image, PBIX, binary and technical bytes are unchanged. New history files are text-only; no source screenshots/attachments are embedded. Targeted exclusion, complete-object and common-encoding checks must be read together with protected-byte equality; generic validator PASS is not declassification authority. Actual check results are recorded by the final build receipt and private validation evidence.
