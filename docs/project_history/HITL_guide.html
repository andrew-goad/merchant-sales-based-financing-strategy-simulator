A short leadership reading route

  1. Ask for the missing why: Merchant 003 question → escalation → source finding.
  2. Challenge the rule, not only the implementation: accepted-rule challenge → counteroffer design reference.
  3. Connect requirements before delegating: execution lessons → reporting request → requirements → human return → build uptake.
  4. Delegate and define the test: mandate → response → 750-application assignment → initial findings.
  5. Accept within a scope: R23 request → recorded acceptance with observations.
  6. Keep judgment active afterward: new monitoring question → business concern → interim sensitivity result → timing hypothesis → policy instruction.
  7. Verify, preserve failures and return: R26 request → decision and failed-run provenance → Power BI handoff → reporting response.
  8. Teach the method: Masterclass, p.23 and returned report review.
