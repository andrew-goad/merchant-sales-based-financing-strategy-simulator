## Run a new Windows experiment

The **RC21 A3 Windows operator** opens the campaign GUI for a new reference and challenger. GitHub’s automatic source archives contain the repository snapshot. Choose the named operator ZIP below for the runnable package. The article covers prerequisites, package verification, setup, parameters, monitoring and opening the resulting reports. ## Verify a download

From the download folder, run `Get-FileHash -LiteralPath '.\YOUR-FILENAME' -Algorithm SHA256` with your filename. Compare the output to its entry in the appropriate checksum file. [Ten workbook checksums](https://github.com/andrew-goad/merchant-sales-based-financing-strategy-simulator/releases/download/msbf-research-assets-2026-11/SHA256SUMS.txt) · [Windows operator checksum](https://github.com/andrew-goad/merchant-sales-based-financing-strategy-simulator/releases/download/msbf-research-assets-2026-11/MSBF_Portable_Windows_RC21_A3.zip.sha256)
