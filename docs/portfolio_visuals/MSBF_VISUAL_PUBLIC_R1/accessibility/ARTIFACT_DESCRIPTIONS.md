# Visual accessibility and reading guide

The original artwork is unchanged. This companion supplies descriptive text and reading order; it is not a claim of WCAG, PDF/UA, tagged-PDF or assistive-technology certification. The pitch and poster PDFs are raster/image-only. Native text in the teaching, cohort and architecture PDFs is retained, but reading order and screen-reader behavior have not been certified.

Use full-resolution files for small labels. Preview images are proportionally rendered navigation aids, not source evidence. The only standalone cohort publications are the accepted PDF and PPTX; the collection contact sheet is a navigation composite, not another cohort report or figure export.
