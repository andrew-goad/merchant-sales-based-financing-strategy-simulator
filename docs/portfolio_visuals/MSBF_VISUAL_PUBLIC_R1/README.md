### What is preserved

All approved source PDFs, PPTX files and selected PNGs in this package are copied unchanged. Individual architecture PDFs are extracted from the reviewed three-page source. New poster PDFs wrap the exact reviewed pixels. Gallery thumbnails and the collection overview are proportionally rendered navigation derivatives, not substituted evidence. No image generation or technical execution is part of this assembly.

`MANIFEST.json` is the payload allowlist; `SHA256SUMS.txt` covers it and every payload file. The two manifest files are the only special self-exclusions. `ARTIFACT_INDEX.json` describes each artifact's role, edition and formats.

The separate **Visual Freeze Control** archive retains provenance, editing masters, review records and validation scripts. It must not be bulk-published. No private raw cohort/source/QA carrier, engine, database, PBIX or standalone font file appears here.
