## 4. Decision reconciliation method

The migration matrix is generated by a crosstab of the exact 1,500-row `predecessor_outcome_code` and `successor_governed_outcome_code` fields.

Required invariants:

```text
Source rows                                  1,500
Migration-matrix grand total                 1,500
Predecessor row totals match source counts   PASS
Successor column totals match R4 outcomes    PASS
Missing/extra application-scenario keys      0
Duplicate comparison keys                    0
```

The public register is `registers/03_DECISION_OUTCOME_MIGRATION_MATRIX.csv`.
