# Public / private boundary for the integrated candidate

## Proposed public repository/release material

- Version-separated R26 integration documentation and readable source projection.
- Exact R26 retained-final runtime ZIP as a **proposed release asset**, subject to final Audit confirmation of public classification and Windows qualification.
- Module 1/2 v2.1 change-control public projection.
- Accepted Power BI R3 public projection and exact accepted support ZIP/PBIX release asset.
- Owner-approved cohort R3 PATCH1 PPTX/PDF and bounded patch documentation.
- Owner-approved visual-publication public tree and exact visual ZIP release asset.
- Public runbook/procedure after final path binding and Windows qualification.
- Sanitized project history after the final Audit interaction is appended and the history validation gate closes.

## Private / audit-only

- Raw ChatGPT CSV/JSON exports and full ingestion carriers.
- Private cohort derivation/source carrier and raw R26/PBI QA evidence not deliberately projected public.
- Visual source/editing masters and private visual-freeze control archive.
- Workstation logs, credentials, database backups/checkpoint carriers unless Independent Audit explicitly accepts a sanitized synthetic checkpoint carrier for public reproducibility.
- Failed/unaccepted visual workspaces and private audit interaction carriers.

A package name containing “publication support” is not by itself a classification rule. The staging builder projects curated public content and keeps control evidence in the audit carrier.
