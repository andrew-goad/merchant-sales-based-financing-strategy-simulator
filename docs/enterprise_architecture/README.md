## Interpretation boundary

All represented merchants, applications, transactions, outcomes, and strategy results are deterministic and synthetic. These exhibits document a governed analytical simulator and accepted consumption boundaries; they do not represent production deployment, live financing operations, legal certification, or a causal-optimization claim. Power BI is represented as an executive-visibility and portfolio-intelligence layer, including **Power BI-ready governed views** where applicable.
