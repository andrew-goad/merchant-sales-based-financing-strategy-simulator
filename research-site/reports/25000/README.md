# 25,000 · AWS GUI

On AWS EC2 Windows, the operator opened an early version of the campaign console from PowerShell, then submitted and monitored the 25,000-merchant run in the browser. Baseline funded 3,337 accounts and Recession Energy funded 1,005.

Place a copy of the selected Power BI Desktop workbook (`.pbix`) and packaged Tableau workbook (`.twbx`) for this study here. Keep their existing filenames. From the repository root, run `python -B tools/register_research_reports.py`, then open `research-site/index.html` and select this study and **Reports**. A single workbook can be registered on its own.
