# Independent Audit boundary

The bounded audit subject is the exact rc2 repository candidate, R17/R19 physical results, the comprehensive 20-object carrier, the R22 PBIP source, the final R22 Desktop evidence, accepted-source diffs, manifests, package receipts, and the inactive supersession plan.

The audit may accept, reject, or hold the candidate. It must not edit GitHub, publish a release, replace accepted Power BI files, execute a database, or authorize Campaign Scale or Module 3 execution.
