# M2.9 Recovery Guide

## Failed Program 196

Click Stop, execute `ROLLBACK;`, then run Program 196A. Accepted M2.8 must remain unchanged and M2.9 objects must remain absent.

## Failed or cancelled Program 198

Click Stop, execute `ROLLBACK;`, then run Program 198A. Programs 196 and 197 remain authoritative and generated M2.9 targets must remain empty.

## Lost Program 198 result tab

Run Program 198B. It reconstructs lifecycle, counts, amounts, hashes, canonical identity, and stress diagnostics without writes.

After committed generation, repair only a proven downstream defect. Do not regenerate accepted M2.9 business tables without evidence of a generation defect.
