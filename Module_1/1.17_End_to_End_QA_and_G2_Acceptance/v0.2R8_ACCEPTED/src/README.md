# M1.17 Public Source Package

M1.17 is formally accepted at package revision **v0.2R8**. The public source directory preserves the exact source artifacts retained in the accepted package and the authoritative source-provenance notes.

The active runtime did not retain standalone copies of the exact v0.2R2 Programs 124C-128 source files. The accepted package therefore preserves their live execution evidence and original-plus-hotfix lineage rather than presenting reconstructed code as byte-identical executed source. See [`SOURCE_PROVENANCE.md`](./SOURCE_PROVENANCE.md).

This provenance limitation affects packaging completeness only; it does not alter the accepted database result, G2 hashes, 128 positive controls, 20 negative controls, or formal sign-off.
