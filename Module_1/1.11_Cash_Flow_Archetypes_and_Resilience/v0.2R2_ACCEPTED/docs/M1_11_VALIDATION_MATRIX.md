# M1.11 Validation Matrix

M1.11 contains 72 blocking positive controls and six fail-closed negative controls.

Validation domains include predecessor governance, cardinality, grains, matched scenario coverage, physical lineage, component bounds and weights, wide/long reconciliation, tier/archetype mapping, stress non-improvement, reason/fallback/review logic, physical hashes, set hashes, generation evidence, stage boundaries, and blocking configuration errors.

The negative controls cover disabled generation, invalid weights, invalid tier ordering, unapproved policy, prerequisite drift, and attempted regeneration.
