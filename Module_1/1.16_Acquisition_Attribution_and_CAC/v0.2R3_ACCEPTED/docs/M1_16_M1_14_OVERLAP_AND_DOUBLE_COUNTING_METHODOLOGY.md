# M1.16 M1.14 Overlap and Double-Counting Methodology

M1.14 remains accepted and immutable. Its acquisition amount is inherited once per application after baseline/stress invariance is proven.

```text
Detailed Total If Booked
= Detailed Incurred + Detailed Conditional

Identified Legacy Overlap
= supported detailed amount already represented by M1.14

Incremental Beyond M1.14
= Detailed Total If Booked − Identified Overlap

Enhanced Total If Booked
= Accepted M1.14 Legacy Amount + Incremental Beyond M1.14

Unmapped Legacy Proxy
= Accepted M1.14 Legacy Amount − Identified Overlap
```

Overlap cannot be negative or exceed either legacy cost or mapped detailed cost. Unknown overlap is not zero overlap. M1.14 contribution and total non-loss cost are not recalculated.
