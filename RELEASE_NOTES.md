## Public Repository Design

The public repository is a curated derivative of the private canonical audit repository. It includes final accepted clean-build source where exact retained source exists, selected execution and validation evidence, formal sign-offs, correction histories, deterministic samples, release metadata, and SHA-256 inventories.

It intentionally excludes private development branches, duplicate project ZIPs, third-party research PDFs, private correspondence and origin records, temporary diagnostics, and machine-specific workspace files.

## Source-Provenance Note

The accepted M1.17 package records that the active runtime did not retain standalone copies of the exact v0.2R2 SQL source files for Programs 124C through 128. The public package preserves the live execution evidence, original-plus-hotfix source lineage, validation history, and formal provenance note. It does not silently reconstruct or falsely label replacement files as byte-identical executed source.

This packaging limitation does not alter the accepted database result, G2 hashes, control results, or formal acceptance determination.

## Interpretation Boundary

All records are deterministic and synthetic. This release is not production underwriting, a calibrated probability-of-default model, CECL or regulatory-capital evidence, legal or accounting advice, a financing offer, or a deployed lending system.

Power BI remains a planned executive and portfolio-intelligence layer and is not represented as implemented in v1.0.0.
